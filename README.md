## ✨ Features

- 🚀 **Made for the TV:** Large tiles, fully usable with the TV remote.
- 🧩 **All media:** Movies, series, music and audio books from your server.
- ⚙️ **Resume playback:** Continue where you stopped, on any device.
- 🔒 **Phone as remote:** Works with GLX Remote on your Android phone.
- 📂 **Two languages:** German and English.
